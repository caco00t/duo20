# DUO 20 · Natalia + Camilo

Mini app de entrenamiento funcional (fuerza) para hacer juntos, optimizada para celular.
3 sesiones por semana · 15–20 min · timer guiado con voz/vibración · progreso y premios.

Es una sola página web (`index.html`) sin servidor ni dependencias. Todo el progreso se guarda
en el propio teléfono (`localStorage`).

## Publicar en GitHub Pages (gratis, con enlace público)

1. Crea una cuenta en https://github.com y un repositorio nuevo, por ejemplo `duo20`.
2. Sube estos archivos a la raíz del repositorio: `index.html`, `icon.svg`, `README.md`.
   (Botón **Add file → Upload files** en la web de GitHub, arrastras los archivos y **Commit**.)
3. Ve a **Settings → Pages**.
4. En **Source** elige `Deploy from a branch`, rama `main` y carpeta `/ (root)`. Guarda.
5. Espera ~1 minuto. GitHub te dará un enlace tipo:
   `https://TU-USUARIO.github.io/duo20/`

Ese enlace es el que abres desde el iPhone.

## Instalar en el iPhone (se siente como app)

1. Abre el enlace en **Safari** (no en Chrome, para que el "añadir a inicio" funcione mejor).
2. Toca el botón **Compartir** ⬆️.
3. Elige **“Añadir a pantalla de inicio”**.
4. Se crea un ícono "DUO 20". Al abrirlo se ve a pantalla completa, sin barra del navegador.

En Android es igual desde Chrome: menú **⋮ → Añadir a pantalla de inicio**.

## Uso rápido

- Arriba eliges perfil: **Natalia**, **Camilo** o **Juntos**.
- Pestaña **Semana**: elige Semana 1–4 y marca los trotes de Natalia.
- Pestaña **Entrenar**: abre Fuerza A / B / C y pulsa **Empezar**. El timer avisa con
  sonido y vibración en cada cambio. La pantalla no se apaga durante la sesión.
- Pestaña **Progreso**: XP, logros, racha de semanas y la sorpresa que se desbloquea
  al completar las 3 sesiones de fuerza de la semana.

## Nota

No sustituye asesoría médica. Ante dolor agudo, mareo o algo fuera de lo normal, se para la sesión.
